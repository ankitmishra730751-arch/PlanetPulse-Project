# 🌱 PlanetPulse

Carbon Footprint Tracker built for the Climate Tech hackathon.

## Features

- Log daily activities
- Calculate CO₂ emissions
- Dashboard with category breakdown
- Weekly CO₂ target and progress
- Activity history
- Filter by activity type and date
- Input validation for unrealistic values
- Monday–Sunday weekly tracking
- Data persistence using localStorage

## Tech Stack

- React
- JavaScript
- HTML / JSX
- CSS
- Vite
- LocalStorage

## CO₂ Factors

| Activity | Factor |
|---|---:|
| Car | 0.20 kg/km |
| Bus | 0.08 kg/km |
| Flight | 0.25 kg/km |
| Electricity | 0.80 kg/kWh |
| Veg Meal | 0.5 kg |
| Non-Veg Meal | 2.0 kg |
